# resume.md 模板

> 把本模板复制为 `~/.tomi-job-hunt/resume.md`（Windows: `C:\Users\你的用户名\.tomi-job-hunt\resume.md`），
> 按自己的真实经历填写。TomiHunt 生成打招呼语时会结合这份简历，匹配度越高，话术越具体、回复率越高。

## 填写原则（影响 AI 话术质量）

1. **量化成果**：写「优化了订单接口，QPS 从 2k 提升到 20k」，不要写「负责接口优化」
2. **关键词对齐**：JD 里常见的词（如 高并发、K8s、微服务、大模型 RAG）如果你做过，用同样的词写出来
3. **真实**：话术会引用简历里的具体内容，虚假经历在面试中会露馅
4. **不用写姓名/电话/邮箱**：TomiHunt 只在本地使用你的简历，不需要联系方式
