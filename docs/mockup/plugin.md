# 浏览器插件 Mockup（无头模式）

> 设计稿：插件**不渲染任何用户操作 UI**。网页内唯一视觉痕迹是岗位列表的匹配度小标记（克制高亮）。全部交互在 Agent UI 悬浮窗（OS 级无边框置顶窗，浮在浏览器上方）完成。
> 悬浮窗 mockup 见 [agent-ui.html](agent-ui.html)。

## 1. 工具栏（Action）

插件图标只做**入口**，不做 popup 操作 UI。点击 → 唤起 / 展开 Agent UI 悬浮窗（待确认项：无 action 或保留此跳转）。

```
        Chrome 浏览器工具栏
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬──────────────────────────┐
│  ⏪  │  ⏩  │  ⟳  │ 🔒  │   xxx.com  │  ⋮  │  🤖  │  👤  │        │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴──▲──┴─────┴──────────┘
                                             │
                                      🤖 TomiHunt（点击）
                                     ├─ 唤起 / 展开 Agent UI 悬浮窗（唯一动作）
                                     └─ 无 popup 面板、无设置按钮
```

- **无 popup**：`manifest` 的 `action` 不设 `default_popup`，`onClicked` → 唤起 / 展开 App 悬浮窗；
- **无设置页**：`options_page` 移除，设置全部在 App 内（`agent-ui.html` 设置页）；
- 图标本身是"无头"的指示：常态灰显（网关离线）→ 高亮（网关在线），仅作状态灯。

## 2. 岗位列表页（Boss直聘）——唯一视觉痕迹

无头插件在列表页**只显示一个匹配度小标记**（信息展示，非操作 UI），其他零 UI。

```
  Boss直聘 · 搜索「Java 后端」
┌─────────────────────────────────────────────────────────────────┐
│ [✓] 高级后端工程师       某某科技   20-30K·14薪   [⚡82 匹配]      │
│     深圳 · 3-5年 · 本科 · 双休                                    │
├─────────────────────────────────────────────────────────────────┤
│ [✓] Go 服务端开发        某某云     25-40K·15薪   [⚡67 匹配]      │
│     杭州 · 1-3年 · 大小周（风险词）                                 │
└─────────────────────────────────────────────────────────────────┘
```

- 标记用**通用样式**（不落 `data-tomihunt-*` 属性，内部用 `WeakMap<Element, score>` 记录，避免页面可枚举）；
- 分数随 Agent UI 的匹配结果异步更新；无 App 时列表页**完全无痕**（不显示任何标记）。

## 3. 聊天页（Boss直聘 / 猎聘）——零 UI

网页内**没有浮动按钮、没有悬浮面板、没有气泡**。插件静默监听并等待控制台指令。

```
  Boss直聘 · 聊天
┌────────────────────────────────────────────────────────────────┐
│  张女士  ▸  某某科技                                (正常页面)   │
│                                                               │
│  你：您好，看到贵司在招高级后端工程师，我 5 年 Java 后端……    │  ← 用户/插件填入
│  对方：你好，背景挺匹配的，最近有在看新机会吗？                 │  ← 静默监听，上报控制台
│                                                               │
│  我明天下午 2 点方便电话面试吗？       [发送]                  │
└────────────────────────────────────────────────────────────────┘
           ▲                                              ▲
     无浮动按钮 / 无面板                           无「AI 生成」气泡
```

控制台点「发送」后，插件的执行是**无痕的**：聊天框填入话术 → 点击发送按钮 → 立即从页面消失成"正常发出的一条消息"。

## 4. 无头执行示意（一次发送）

```
 Agent UI（悬浮窗）                   页面（Boss直聘聊天）
┌───────────────────────┐          ┌──────────────────────────┐
│ 📤 发送到聊天框          │ ──网关──▶ │ 填入话术（原生事件）       │
│    目标：张女士·在线     │          │ 点击 [发送]（脚本事件）     │
│                        │◀─Ack──── │ ✔ 已发出，消息出现在会话   │
└───────────────────────┘          └──────────────────────────┘
```

失败时（目标窗口已关 / 选择器失效）→ 悬浮窗展示失败原因与现场（见架构 §4.3/§4.4）。

## 5. 设计原则汇总

| 原则 | 落地 |
|---|---|
| 网页内零操作 UI | 删浮动面板/设置入口/提示气泡 |
| 唯一视觉痕迹 | 列表页匹配度小标记（可整体关闭） |
| 唯一交互入口 | 工具栏图标 → 唤起 / 展开悬浮窗 App |
| 状态可见 | 图标灰/亮 = 网关离线/在线 |
| 失败可观测 | 执行失败 → 悬浮窗展示原因 + DOM 片段（可选截图） |
