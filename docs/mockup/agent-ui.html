设计点说明
以 JD 为单位 左侧 JD 库（浏览时自动收集，非浏览器镜像）+ 右侧工作台：选中一个 JD，其全部能力集中在一个工作区，而不是散落在全局"聊天 / 功能 / 设置"里。
功能并列 右侧 tab 为同一 JD 的并行功能：💬 聊天（气泡 + 话术 + 发送 + 👍👎）· 📄 简历匹配（分环 + ✓优势 / △差距 / !避坑）· 🎤 模拟面试（逐题问答 + AI 点评 + 历史）· 💬 反馈（本 JD 的匿名反馈）。
悬浮窗形态 仍为 OS 级无边框置顶窗（frame:false + alwaysOnTop + skipTaskbar），窗头可拖动；离开聊天页自动折叠成胶囊（右下角「折叠胶囊」预览）。
跟随活跃 Tab 浏览器当前打开的 JD 聊天 → 左侧该项自动高亮 + 右侧自动切到该 JD；用户也可在左侧自由切换任意 JD。
设置入口 窗头 ⚙️ 打开设置浮层（DeepSeek / 简历 / 自启 / 插件管理），不占工作台 tab。
广告位 窗口底部细条（💝 支持项目 / 推广返佣 / TomiLite / 社区入口，链接占位）。
