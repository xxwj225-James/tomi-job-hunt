# TomiHunt HR 速筛（独立网页 · 不依赖浏览器插件）

粘贴 JD + 批量上传候选人简历 → AI 本地打分排名（**约面 ≥80 / 待定 60-79 / 婉拒 <60**）。简历与 API Key 全部留在本机浏览器，不上传任何服务器。

## 使用

**方式一（推荐）：一键启动**

1. 打开本目录下的 `start.bat`（Windows）——自动起一个本地服务并打开浏览器
2. 首次使用：填入 **API Key**（申请路径见页面内引导）→ 保存（保存时会自动测试连接）
3. 粘贴 JD 原文 → 上传简历（PDF / .docx / .txt / .md，可多选）→ 开始速筛

**方式二：双击 `dist/index.html`**——无需任何环境，但 PDF 解析会退化为单线程（大量 PDF 时略慢），且个别模型 API 会拒绝 file:// 来源，此时请改用方式一。

## 构建（开发者）

```bash
npm install                # 首次
npm run build -w hr        # 产出 hr/dist/
npm test -w hr             # 单测
```

## DeepSeek API Key 申请路径

1. 打开 [platform.deepseek.com](https://platform.deepseek.com)，手机号注册登录
2. 完成**实名认证**（免费、必须）
3. 充值 **¥10-20**（支付宝/微信，不退款；筛一份简历成本约几分钱）
4. 「API keys」→ 创建 → 复制 `sk-` 开头的 Key（**只显示一次**）
5. 回页面粘贴 → 点保存（自动测试连接）

## 隐私

- 所有简历与 API Key 只存于**本机浏览器 localStorage**，本页不连任何服务器
- 只有「JD + 简历文本 + 提示词」会发送给你选择的模型 API（OpenAI 兼容：DeepSeek / Qwen / Kimi / 自填）

## 使用需求反馈

页面底部有需求收集表单（多选 + 说明）。当前为**离线收集**：保存到本机后「复制 / 导出」，可发给作者（GitHub Issue / 邮件）。TomiHunt 正在开发 HR 版（在线简历分析、导出 Excel 等），你的需求直接决定下个版本做什么。

## 说明

- 旧版 `.doc` 简历无法在浏览器解析——请让候选人另存为 .docx 或导出 PDF
- 扫描件 PDF（纯图片）无法提取文本，会标记为解析失败
- 打分失败的单份简历会标「未评分」并置底，可单独重试，不中断整批
